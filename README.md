# Focus Flow

A lightweight focus app designed to work well on iPhone browsers and as a home-screen web app.

## Features

- Pomodoro-style Focus/Break timer
- Quick duration controls
- Top task reminder persisted in local storage
- iPhone-friendly layout with safe-area support
- Optional notifications + vibration when a session ends
- Offline support via service worker

## Run locally

Use any static server from this folder. Example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Add to iPhone home screen

1. Open the app in Safari.
2. Tap the Share icon.
3. Select **Add to Home Screen**.
4. Launch it from your home screen for a near-native experience.
